# Kingshot GEO Audit Report

Audited on 2026-09-18. This report distinguishes content present in raw HTML from content available only after client-side rendering.

## Existing Strengths

- Hero static pages already expose localized H1, summary, basic facts, related heroes, canonical, hreflang, OG, and breadcrumb data in raw HTML.
- The site maintains common JSON sources for heroes and calculators rather than duplicating numeric data in each language.
- Four-language static routes use `ko`, `en`, `ja`, and `zh-TW`; Traditional Chinese HTML uses `zh-Hant`.
- Direct localized HTML pages provide substantial raw content for buildings, pets, masters, and guides.
- Gift-code automation separates published, candidate, and conflicted records instead of exposing weak evidence.

## Remaining GEO Gaps

- Existing hero records do not consistently carry record-level `verifiedAt`, `sources`, `confidence`, or `sourceType`.
- Building, pet, gear, charm, troop, and research-oriented datasets have uneven or absent provenance.
- Research, items, and Alliance Tech lack authoritative entity records, so reliable Fact Blocks cannot yet be generated.
- Existing guide pages use varied related-link conventions rather than a single data-driven relation layer.
- The gift-code guide should be separately checked to ensure active status, evidence count, and last checked time are visible in raw HTML, not only at runtime.
- Legacy database/chart records need freshness classification before they can be presented as answer-engine facts.
- Empty optional event fields are correctly hidden, but future records need translation completeness checks to prevent raw key exposure.

## Automated Audit Result

- `npm run audit:seo` inspected all 461 sitemap URLs after static generation.
- Blocking findings: 0 missing files, metadata failures, canonical mismatches, invalid JSON-LD blocks, broken local images, duplicate titles, or duplicate canonicals.
- Follow-up warnings: 121 unique findings. These are primarily existing client-routed aliases whose pretty URL has no matching local file and older pages without JSON-LD.
- The warning set is retained as a backlog signal; this change does not rewrite unrelated masters, pet, guide, or building URLs.

## Thin Or Deferred Areas

- `/events/` is intentionally concise: it is an entity index, while details own the canonical facts.
- Event scoring, reward tables, and fixed calendars were deferred because evidence was incomplete or schedules are variable.
- Items, Academy Research, Advanced War Academy, and Alliance Tech remain deferred rather than producing thin pages.
- `llms.txt` was not added. Crawlability, sitemap integrity, raw HTML, provenance, and source freshness have higher priority.

## Recommended GEO Follow-up

1. Add field-level provenance and verification dates to existing source datasets as each category is revalidated.
2. Extend common Fact Block generation to buildings and pets after provenance is normalized.
3. Add structured item and research entities only when two-source numeric verification is available.
4. Generate related content from stable IDs across heroes, events, items, research, and calculators.
5. Run the static metadata and link audit in CI after every route-generation change.
