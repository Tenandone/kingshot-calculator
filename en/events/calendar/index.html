Timing rules and scope

KvK uses a 28-day estimate anchored to preparation on 26 January 2026 at 00:00 UTC. New kingdoms and differently aligned servers may not follow it.

Published provisional windows take priority. Beyond the list, only one window 56 days after the last start is estimated. Later dates require new data.

The kingdom number selects a reference group. It does not establish an open date, first KvK date or kingdom-specific offset.

Times are UTC. Transfer phase changes at midnight reflect the reference site’s calculation, not officially confirmed game start times.
