# KingShotData royal bear identity

The orange royal bear remains the brand character. Its gold crown, blue diamond,
dark brows, plum nose and tapered chin are the recognition cues. Do not replace
it with a generic bear, emoji or independent game logo.

## Assets

- `bear-master.png`: transparent 1254 px character master, built-in ImageGen,
  refined from the previous site bear. Use for large visual applications.
- `bear-symbol-{112,224,512}.png`: header and reusable transparent symbol exports.
- `bear-micro-master.png`: separately redrawn simplified small-size artwork.
- `favicon-{16,32,48}.png`: optical-size family exported from the micro artwork.
- `/favicon.ico`: the same 16, 32 and 48 px RGBA PNG frames.
- `apple-touch-icon.png`: opaque 180 px dark-forest home screen tile.
- `pwa-{192,512}.png`: opaque app tiles with artwork inside the maskable safe circle.
- `wordmark-*.svg` and `brandmark-*.{svg,png}`: retired text-lockup exports retained
  for release history only. They are not used by the current site.

## Usage

Use the unframed bear alone at 52 px in desktop headers and 44 px on mobile.
The desktop home link has a 64 × 60 px target and mobile uses 52 × 52 px.
Do not pair it with a wordmark, subtitle or additional visible brand name.
Keep the accessible name on the home link. The released width belongs to
navigation: larger desktop labels, a mobile search shortcut, language controls
and the menu. Do not add the previous rectangular/pentagonal background.
For 16–48 px application use the micro family, not a reduction of the detailed
master. 16 px communicates the crown, blue jewel and warm bear face; detailed
expression is reserved for larger artwork.

Palette: forest #142E26 / ink #173E31 / cream #F7F4E8, with orange bear fur,
gold crown, sapphire jewel and plum nose retained from the original identity.
Retired outlined typography was based on Liberation Sans Bold (SIL OFL); see
`typeface-license.txt`. Current branding has no wordmark or font dependency.

The web manifest adds launch icons only. This release adds no service worker,
offline cache, calculation logic, data changes or revised game affiliation.
